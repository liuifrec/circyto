# RERF/Radiation Positioning

The primary RP objective remains clone identification and cell-state analysis. circyto provides an additional exploratory layer that can use the same full-length RamDA/ShinRamDA data to evaluate circRNA and other noncanonical RNA features in relation to clone status, genome instability, and radiation-associated cellular states.

## Conservative Position

- `circyto` is preparation for future RamDA/ShinRamDA additions to RP1-23-1.
- Public scRR-seq demonstrates feasibility of linking circRNA profiles with DNA-derived genome-state features.
- Current public analyses should not be claimed as radiation-exposure results.
- Radiation biology should be positioned as motivation and future application unless radiation-specific data are analyzed later.

## Practical Use in RP Work

The framework can add these exploratory layers to clone and cell-state analyses:

- circRNA burden and host-gene programs.
- circRNA programs associated with inferred clone status.
- circRNA programs associated with CNV or replication timing when matching DNA-derived genome-state data exist.
- RNA-derived candidate variant signal summaries when SComatic-style interoperability is used.

These additions should remain secondary to clone identification and cell-state analysis until larger radiation-specific datasets are processed.
